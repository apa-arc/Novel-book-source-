## 与当前阅读器书源格式的兼容风险

当前订阅要求四个 appConfig endpoint：searchUrl、bookUrl、chapterListUrl、chapterUrl。现有阅读器支持的是受限 CSS HTML 规则和有限 JSON 字段映射，不执行仓库中的任意 JavaScript。

REST 搜索响应的结果位于 `pages[]`，单条结果主要使用 `title`、`key`、`excerpt` 等字段；目前不能假定阅读器会把 `key` 自动转换成 bookUrl。作品详情、目录和正文的 HTML 结构也尚未在目标 App 中完成真实解析验证。

因此：
1. 不能仅凭 REST API 可访问就认定搜索可用。
2. 不能将作品页的所有链接粗略当成章节目录。
3. 不能把章节页的导航文字混入正文。
4. 不能用仓库脚本测试代替目标 App 的实际导入和解析测试。
5. 在四接口均有真实响应、正确字段映射和干净正文抽样前，必须保持禁用。

## 后续验收步骤

- 验证搜索请求是否能在现有 App 中返回书名、作者及可打开的作品 URL。
- 验证作品详情字段。
- 验证目录是否完整、顺序正确、无重复和非章节链接。
- 验证章节正文选择器只提取正文，排除上一回/下一回、目录、页眉页脚等。
- 抽样多回检查乱码、空内容、重复内容和正文污染。
- 保存不含正文的功能测试报告及质量报告。
- 单独复核作品版本及许可依据。
- 全部通过后才可将该作品源加入普通订阅；不属于成人源。

## 当前结论

《三国演义》是有明确公版依据且存在完整分回页面的候选作品，但目前尚无符合仓库正式启用门禁的四接口功能测试报告。当前普通订阅和成人订阅均不因此增加源数量。
