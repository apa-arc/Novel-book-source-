# 中文维基文库古典作品适配候选

- 来源主页：https://zh.wikisource.org/
- 示例作品：《三国演义》
- 示例章节：由维基文库搜索结果发现的 `三國演義/第001回`
- 版权政策：https://zh.wikisource.org/wiki/Wikisource:版权信息/全文

## 当前能力

适配器实现搜索、作品详情、目录章节链接提取和章节正文提取四个接口。它只通过阅读器注入的 `http.get` 请求页面，并限制在 `zh.wikisource.org` 域名。

## 真实联网检查

GitHub Actions 的 `Wikisource live smoke test` 已通过。该检查使用 Node.js 原生 HTTPS 请求维基文库 MediaWiki API，确认搜索 API 有返回、作品页 HTML 可读取，并通过站内搜索发现第一回页面后成功读取章节 HTML。

这项检查验证的是上游 API 和页面可达性，不等于已经验证本仓库适配器在 iPhone 阅读器中的真实 DOM 解析，也不证明作品目录链接提取已完成联调。模拟 DOM 测试与真实宿主测试仍是两回事。

## 版权与状态

该适配器是禁用候选（`enabled: false`），不是正式可用书源。维基文库收录内容包含公有领域作品及特定许可作品；必须逐项检查作品页面的版权标记和使用地区，不能因站点总体政策而推断每一篇作品均可任意使用。该项目当前没有内置作品级版权过滤。

## 验证边界

仓库测试使用模拟 DOM fixture，验证四个接口、URL 白名单和基本解析流程。在线 smoke test 验证上游 API 与页面可达性。尚未在目标 iPhone 阅读器的真实 HTML DOM 实现中完成联调，也未完成作品级许可审查。只有完成这些工作后，才可考虑启用并发布到订阅清单。
