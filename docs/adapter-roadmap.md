# 双路线适配计划

## A. 正版平台（kind: official）

接入优先级：
1. 官方开放 API 或公开开发者接口。
2. 平台明确允许的网页访问方式。
3. 用户自行提供、且符合平台条款的授权接口配置。

边界：
- 不破解客户端私有协议。
- 不绕过登录、订阅、付费墙、验证码或 DRM。
- 不把用户账号密码、Cookie 或令牌写入仓库。
- 如需用户授权，凭据由 App 的安全存储管理，解析器只能使用最小权限请求桥。

## B. 公开小说网站（kind: public-web）

接入条件：
- 网站允许自动化访问，且内容来源和使用方式有合法依据。
- 只请求配置中列出的 HTTPS 域名。
- 遵守 robots、访问频率、版权声明和网站服务条款。
- 不提供规避反爬、验证码或访问控制的功能。

## 统一解析接口

所有适配器提供：
- `search({ keyword, page, http })`
- `getBookDetail({ bookUrl, http })`
- `getChapters({ bookUrl, http })`
- `getContent({ chapterUrl, http })`

## 开发顺序

1. 选定一个允许接入的正版平台，完成一套端到端适配。
2. 选定一个允许自动化访问的公开网站，完成一套端到端适配。
3. 在 AppleNovelApp 中实现受限 JS 运行与 HTTP 桥接。
4. 用真实搜索、目录、正文和朗读流程验收。
5. 再扩展更多站点。

## 验收标准

- 搜索结果字段完整且链接可打开。
- 详情、目录、正文解析稳定。
- 章节顺序正确，正文无明显导航/广告残留。
- 请求仅访问白名单 HTTPS 域名。
- 解析器失败时有清晰错误，不影响书架和本地阅读。
