# 第七轮：组合表达式安全诊断

日期：2026-11-20

## 本轮实现

转换器新增了保守的组合表达式结构扫描：

- 识别 `&&`、`||`、`%%` 运算符，并记录出现顺序及操作数数量。
- 识别 `##...##...` 正则变换分隔符和 `###` OnlyOne 结尾标记。
- 扫描时跳过转义字符、引号字符串和方括号内部内容，避免把属性值中的符号误认成顶层组合运算符。
- 只输出运算符列表、分隔符计数、OnlyOne 标记等结构元数据，不输出原始规则表达式。

## 重要边界

本轮**没有**把组合表达式升级为 `candidate`，也没有声称已经实现其运行语义：

- 尚未验证 `&&`、`||`、`%%` 的真实求值顺序、空值行为和嵌套优先级。
- 尚未执行正则表达式，也未实现替换规则或 OnlyOne 的运行时行为。
- 结构扫描结果只用于后续人工审查和测试用例设计，不是可运行 Selector IR。
- 不执行上游脚本，不导入 Cookie、请求头凭据或登录信息。
