# AppleNovelApp 书源联调测试包

本文件只描述书源仓库提供的测试材料，不修改 AppleNovelApp。

## 1. 当前可测试范围

- 订阅清单下载、JSON 解析、版本识别、来源列表展示：可用普通订阅和成人订阅测试。
- 模拟书源导入、搜索结果展示、详情、目录、正文阅读：使用下方开发模拟数据测试。
- 真实站点搜索与抓取：当前没有通过许可和四接口门禁的正式书源，暂不可测。

## 2. 固定订阅地址

普通书源：
`https://raw.githubusercontent.com/apa-arc/Novel-book-source-/main/subscription.json`

成人书源：
`https://raw.githubusercontent.com/apa-arc/Novel-book-source-/main/adult-subscription.json`

当前两个订阅均为 0 个正式书源。空订阅是有意的安全状态，不代表导入失败。

## 3. 本地模拟联调文件

从仓库下载以下两个文件，放到测试设备或 App 测试工程可读取的位置：

- `development/mock-source.json`：模拟来源配置
- `development/mock-responses.json`：原创模拟响应数据

模拟域名使用保留域名 `mock-api.example.invalid`，不会连接真实网站。App 应将模拟响应作为本地 fixture 注入网络层，不要尝试访问该域名。

模拟书籍：**星海来信**（原创测试数据）
- 搜索：关键词“星海来信”，返回 1 本书
- 详情：作者“书源测试组”，状态完结
- 目录：3 章，顺序为第一章、第二章、第三章
- 正文：每章均有非空中文文本

## 4. 建议测试顺序与通过标准

1. 分别下载两条订阅地址，确认返回合法 JSON，`schemaVersion=1`、`sources` 为数组、`sourceCount` 与数组长度一致。
2. 确认普通订阅和成人订阅使用不同的 `subscriptionId`，互不混入。
3. 导入空订阅时，App 显示“暂无正式书源”或等价空状态，不崩溃、不误报导入成功的书源数量。
4. 从本地加载模拟配置与响应，执行搜索；结果列表应显示“星海来信”。
5. 打开详情，确认书名、作者、简介等字段展示正常。
6. 加载目录，确认 3 章且顺序正确。
7. 依次打开三章正文，确认中文、换行、段落显示正常，阅读进度可正常更新。
8. 断网后重复打开已加载的本地模拟数据，确认本地 fixture 测试不依赖外网。
9. 确认模拟来源标记为开发测试、默认禁用，绝不写入正式订阅或正式书架来源统计。

## 5. 缺陷回报格式

请记录：设备/iOS版本、App版本、测试步骤、预期结果、实际结果、错误截图或日志。优先反馈订阅解析、字段映射、章节排序、正文排版和阅读进度问题。

## 6. 重要边界

模拟数据只用于验证 App 的导入与阅读链路，不代表真实书源可用性，也不能作为真实站点功能测试报告。正式书源只有在许可证据、真实搜索/详情/目录/正文四接口、章节文本质量和 CI 全部通过后才会进入订阅。
