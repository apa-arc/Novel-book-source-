# 文章乱码扫描器

## 用途

`runtime/text-quality.js` 提供纯文本质量检查，不联网、不改写、不自动修复文章。它用于发现可能的字符编码损坏，并将短文本、空内容单独标记为需要人工检查。

## 检测规则

- Unicode 替换字符 `�`。
- 常见 UTF-8 解码错位痕迹，如 `Ã`、`Â`、`â€`、`ä¸`、`å`、`æ` 等组合。
- 常见错误替换文本，如 `锟斤拷`、`烫烫烫`、`屯屯屯`。
- 不应出现在正文中的控制字符。
- 空文本和过短文本会进入人工复核。

## 状态

- `normal`：没有命中当前规则。
- `suspect`：命中疑似乱码或异常控制字符。
- `review`：正文为空或过短，需要人工判断。

检测采用保守规则。古籍中的繁体字、异体字、生僻字、旧式标点不会仅因“不常见”而被判为乱码。`normal` 不代表文章内容绝对正确；语义错字、OCR 错字、漏段、重复段落和图片中的文字需要其他专门检查。

## 真实扫描结果

2026-11-20，GitHub Actions 通过维基文库 MediaWiki API 扫描《三国演义》目录中发现的 120 个回目页面，读取页面原始 wikitext 后逐篇检查：

- 扫描页面：120
- 命中疑似乱码：0
- 需要人工复核（空/过短）：0

这是针对该作品当前上游文本的一次扫描结果，不代表所有维基文库文章均已扫描，也不保证不存在语义性错误。
