# 文章质量扫描器

## 用途

`runtime/text-quality.js` 提供可复用的纯文本与文章批量质量检查。它不联网、不改写、不自动修复文章；网络读取由具体小说来源的扫描任务负责。

## 检测规则

- Unicode 替换字符 `�`。
- 常见 UTF-8 解码错位痕迹，如 `Ã`、`Â`、`â€`、`ä¸`、`å`、`æ` 等组合。
- 常见错误替换文本，如 `锟斤拷`、`烫烫烫`、`屯屯屯`。
- 不应出现在正文中的控制字符。
- 空文本和过短文本进入人工复核。
- 足够长且去除空白、常见引号书名号后完全相同的文本标记为重复内容。

## 状态

- `normal`：没有命中当前规则。
- `suspect`：命中疑似乱码、异常控制字符或重复内容。
- `review`：正文为空或过短，需要人工判断。

检测采用保守规则。繁体字、异体字、生僻字、特殊标点不会仅因“不常见”而被判为乱码。 `normal` 不代表文章内容绝对正确；语义错字、OCR 错字、漏段、段落错序和图片中的文字需要其他专门检查。重复检查只识别完全一致的规范化文本，不判断近似重复。

## 批量接口

`scanArticles([{ title, content }, ...])` 返回 `summary` 和逐篇 `results`，可以复用于任何小说书源导出的章节正文。运行时不负责抓取网页，来源适配器或宿主程序应先取得文章文本，再调用该接口。

## 本地测试

运行 `node scripts/test-text-quality.js` 或 `npm test`。
