## 执行规则

1. 先核实站点当前是否提供公开、稳定的小说搜索、详情、目录和正文页面。
2. 许可状态必须单独核实；网站可访问、第三方目录转载书源或上游仓库开源，不自动授予站点内容或规则分发权。
3. 不复制未获授权的第三方规则，不迁移 Cookie、账号凭据，不绕过验证码、登录、付费墙或其他访问控制。
4. 对同站点的重复记录保留来源 ID 和历史元数据，适配器按站点去重。
5. 成人类别不自动抓取或适配。
6. 只有许可依据、目标阅读 App 四接口实测、正文质量报告全部通过，才可加入正式订阅。
