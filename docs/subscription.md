# 小说源订阅

本仓库只保留一个对 App 展示的订阅入口，名称为 **小说源**。

## 唯一订阅地址

`https://raw.githubusercontent.com/apa-arc/Novel-book-source-/main/subscription.json`

普通小说与成人小说统一归入“小说源”，不再拆分为两个订阅，也不再要求用户单独添加成人订阅。

## 收录与维护

- 来源统一显示在“小说源”订阅中；成人题材不再单独建立订阅入口。
- 新来源完成合法来源依据、App 原生格式转换、HTTPS 域名白名单和解析器结构检查后，可先以“未验证”状态进入订阅；网站 HTTP 404、403、5xx、DNS 或超时不单独阻止导入，后续再修复或标记。
- 不得把旧版 Legado 规则原样混入 Source Format v1 清单；必须先转换成 App 可识别的书源格式，避免订阅导入失败。
- 旧版成人规则文件 `adult-subscription.json` 暂作历史归档，不作为第二个订阅入口；其中规则需逐条转换后并入唯一订阅。
- 订阅清单只放书源配置与解析器地址，不放 Cookie、账号凭据、令牌或小说正文。

## 兼容性

订阅清单提供书源目录与文件地址。阅读器需要实现本仓库的 Source Format v1 和解析器宿主接口，详见 [书源格式规范](source-format.md)。
