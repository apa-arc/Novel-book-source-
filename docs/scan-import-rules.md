# 扫描与正式导入规则

依据 AppleNovelApp 在 2026-11-21 对《斗罗大陆》《斗破苍穹》的搜索记录制定。机器可读规则见 `config/source-scan-import-rules.json`。

## 搜索阶段分档

- **搜索合格**：两个关键词的请求都成功，且至少一个关键词返回至少 1 条有效书目。
- **零结果复测**：请求本身成功但结果数为 0。它不是网络错误，但也不能单独作为可导入依据；换另一个关键词复测。两个关键词都为 0 时不进入正式导入。
- **搜索失败**：连接失败、HTTP 403、跨域跳转、超时或其他非成功 HTTP 状态。先修复请求地址、重定向白名单或站点可达性；不绕过验证码、登录、付费墙或访问控制。
- 不能仅凭站点首页 HTTP 200、静态 JSON 格式正确或搜索接口返回 200 判定书源可用。

## 正式导入门槛

必须全部满足：
1. 普通小说来源，排除成人/色情/绅士源及不适合普通书架的内容源。
2. 许可或规则分发依据明确，保留可核实证据。
3. 《斗罗大陆》《斗破苍穹》两次搜索请求均成功，至少一个关键词有有效结果；零结果要保留原始结果数，不得伪报成功。
4. 搜索结果可打开详情；详情标题正确。
5. 目录非空、章节链接有效且属于 HTTPS 域名白名单。
6. 首章和末章正文均可读取，并通过文本质量检查。
7. AppleNovelApp 原生运行时四阶段测试通过。仅通过 CI、首页探测或云端 curl 不算 App 实测。

## 2026-11-21 实测基线

- 搜索成功 10 条，其中有结果 7 条、零结果 3 条。
- 搜索失败 17 条。
- 五条在四阶段报告中无报错：壁落小说、笔趣阁小说网（17177）、笔趣阁info、豆花文学、52书库（男频武侠）。
- 新笔趣阁小说网、第八中文网搜索有结果，但目录 HTTP 404，必须修复目录后再导入。
- 九一中文、千千小说、爱阅吧网请求成功但零结果，归入搜索复测，不算搜索失败，也不算合格导入源。

## 维护原则

- 新发现的来源先进入候选扫描队列，不直接写入唯一正式订阅「小说源」。
- 每个候选都记录两关键词的请求状态、结果数、错误类型和测试时间。
- 只有通过上述全部门槛的普通小说源才能正式导入；不通过的修复或淘汰，不保留“候选源”冒充可用源。
