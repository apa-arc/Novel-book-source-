# 书源来源调查记录

更新日期：2026-11-21

本记录用于区分“存在技术接口”与“获得小说内容接入授权”。任何调查线索均不自动成为正式书源。

## 本轮调查

### 阅文集团文学 API

- 官方文档：https://open.yuewen.com/docs/yphz/
- 文档说明其提供落地文学 API 与在线文学 API：在线模式可提供书籍非内容信息，并对章节内容实时请求。
- 这是目前发现的、与现代网络小说接入目标最匹配的正规合作路线。
- 当前限制：公开文档不等于已获接入资格或内容授权；尚未取得合作方账号、接口凭证、授权范围及可供本 App 使用的具体接口协议。
- 状态：`partnership-required`，不生成书源、不进入订阅。

### 快手小说剧开放平台接口

- 官方文档：https://open.kuaishou.com/docs/operate/specification/integrationGuide/apiGuide.html
- 文档说明接口需要 appId、AccessToken 和 `scope.ks.novel` 权限，并明确当前接口未对外部开放，需要联系运营申请权限。
- 状态：`not-publicly-available`，不尝试调用内部接口、不绕过权限。

### 第三方小说网站候选

- AOAOSTAR/Legado 扫描出的候选站点仍仅为元数据线索。
- 静态规则字段齐全、网站页面可访问、或第三方书源合集公开，都不等于站点授权本仓库分发规则或自动化读取小说正文。
- 对服务条款禁止爬虫/批量抓取的站点，不进行自动化适配；许可未核实的站点继续保持禁用。
- 不把“搜索引擎能搜到”“无需登录即可阅读”当作自动化抓取许可。

## 正式订阅准入条件

每个来源必须分别具备：

1. 可追溯的内容权利或明确书面授权，覆盖本项目实际使用方式。
2. 允许 App 通过所声明接口访问书籍元数据、目录和章节内容。
3. HTTPS 四接口真实联调：搜索、详情、目录、正文。
4. 目标 App 可直接导入的 appConfig，不依赖 App 不支持的仓库脚本。
5. 正文质量抽样和质量报告通过。
6. 主分支 CI 校验及订阅构建通过。

## 下一步

优先推进有正式合作渠道的现代网络文学 API；其次仅评估明确允许第三方客户端接入、且能提供可核验授权的原创小说站点。没有授权时宁可保持订阅数量为零，也不把未获许可的抓取规则伪装成正式书源。

## 2026-11-21 补充核验：可用 API 与授权边界

### 阅文文学 API（优先合作路线）

- 接入指南明确要求先联系阅文商务沟通合作方案、填写渠道产品接入信息表；合作方邮箱激活、提交审核后，审核通过才可在开放平台查看 appKey 等配置，并设置 IP 白名单。
- 官方接口文档已公开书籍列表、书籍信息、章节目录、章节正文等接口定义；落地 API 的章节正文接口使用合作方 appKey/appToken。在线 API 的章节内容按实时请求处理。
- 因此这条路线在技术上具备完整四阶段能力，但必须先取得合作账号、有效凭据、IP 白名单及明确的内容使用授权。当前仓库和维护者尚未获得这些材料，不能伪造 appKey，也不能把官方示例参数当成有效凭据。
- 参考：开放平台接入指南 https://open.yuewen.com/docs/1000.html；落地 API https://open.yuewen.com/docs/1003.html；在线 API https://open.yuewen.com/docs/1012.html
- 状态：`partnership-required`，列为首要正式接入目标，尚不生成可用订阅源。

### DaoSearch API（只作为元数据发现，不作为阅读源）

- 官方开发者文档说明其 API 覆盖起点、番茄、晋江、飞卢、七猫、纵横、17K、SF轻小说、刺猬猫等平台，提供书籍搜索和目录数据。
- 文档明确说明章节正文不会通过该 API 返回；API Key 需由账户创建，且需遵守调用限额、署名和用途条款。
- 因缺少正文四阶段能力，它不能独立构成完整阅读书源；本仓库不将其包装成可阅读源，也不将其加入正式订阅。
- 参考：https://daosearch.io/developers
- 状态：`metadata-only`，不进入正式订阅。

### 新发现候选：智鸮 Owlite 公版书库

- 书库入口：https://k6-12.com/books
- 站点自述收录 1,337 本公有领域作品，包含《红楼梦》《水浒传》《三国演义》《西游记》等中文小说，也包含其他语言作品；页面提供在线阅读和 EPUB 下载。
- 实际打开《红楼梦》阅读页后，页面显示“这本书没有目录”，正文仍处于异步加载状态；公开页面尚未证明可供第三方客户端稳定调用的搜索、详情、章节目录、章节正文四接口，也未核实站点是否允许外部阅读器批量调用其页面/下载接口。
- 公版作品本身不自动代表站点数字版本、整理文本和服务接口都允许再分发。站点的概括性声明也不足以替代逐版本权利核验。
- 状态：`candidate-needs-api-and-terms-review`。暂不加入订阅；后续只在查明可用接口、目录数据结构及第三方接入许可后再适配。

### 新发现候选：第十三区单本原创站

- 接口文档：https://zone13.cn/api-docs
- 文档公开说明搜索接口固定返回单本作品，并提供详情、目录、章节正文接口；整库导出需要密钥。
- 该站点当前公开阅读接口针对单本原创作品，不是多站点或多书库搜索源；整库导出需额外密钥，且未核实作者授权范围是否允许第三方阅读器集成。
- 状态：`single-title-only`，不符合用户要求的完整多书源订阅，不加入订阅。

### 新发现候选：静读阁

- 站点：https://novelmix.com.cn/
- 首页宣称收录公版全文和出版社授权试读，但当前核验页面包含大量无法独立验证的书库规模、运营数据和内容来源描述；未发现可核验的开发者 API/第三方客户端接入许可。
- 状态：`unverified-claims-no-public-api`，不抓取、不加入订阅。

### 结论与当前阻塞

- 目前已核验到一条具备完整内容接口定义的正式路线（阅文），但需要合作方审核和密钥；没有密钥时无法真实请求搜索、目录和正文。
- 公版书库候选可能补充经典作品，但尚未证明能通过 App 兼容的四接口读取；不能把 EPUB 下载页或单本阅读页面伪装成完整书源。
- DaoSearch 缺正文；第十三区目前仅单本；静读阁没有可核验的 API 和接入许可。
- 继续保持普通/成人订阅为空，直到真实接口凭据、权利依据、App 端四阶段测试和质量报告全部齐备。不得以模拟数据、示例密钥或仅元数据接口填充订阅。
