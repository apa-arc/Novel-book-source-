# 跨平台推广名别名搜索

别名库不是正文书源，也不依赖某个推广平台。

## 搜索规则

1. App 下载统一订阅中的 alias-dictionary 数据。
2. 用户输入关键词后，对输入和别名做 NFKC、大小写及标点/空白规范化。
3. 只对完整别名做精确匹配；不做模糊猜测。
4. 唯一匹配时，用记录中的真实书名作为搜索关键词，并将作者作为结果核验/去重条件。
5. 将真实书名提交给所有已启用正文书源，不按 platform 字段筛选来源。
6. 多条记录同时匹配时标记歧义，不自动选书；无匹配时按原关键词正常搜索。

platform 或 evidence.platform 仅为可选溯源信息。未知平台时可以省略。平台字段绝不能成为搜索路由条件。

## 记录原则

- 只收录已由用户确认或有可靠证据支持的映射。
- 保存真实书名、作者和推广名；作品 ID 可在确认后补充。
- 不把相似书名、题材词或猜测写成正式别名。
- verification 用于区分用户确认、外部证据和待核验状态。
