# 个人小说书源仓库

这是一个独立的书源文件仓库，专门用于整理、维护和分发可由阅读 App 导入的网络小说书源配置。

**本项目只做书源，不开发或托管小说网站、在线阅读平台、用户系统或服务器服务。**

## 书源适配方向

重点适配网络小说网站，覆盖小说搜索、书籍详情、章节目录和正文解析。来源按站点逐个适配，优先选择公开可访问、结构稳定且具备合法使用依据的来源。**不收录任何维基类来源，包括维基文库、维基百科及其镜像/衍生站点；古籍资料库也不作为本仓库的小说源方向。**

## 书源格式

书源由 JSON 元数据和 JavaScript 解析器组成。字段、解析器方法和统一返回结构见 [书源文件格式规范](docs/source-format.md)。

## 仓库内容

- `sources/`：书源 JSON 配置
- `index.json`：书源总索引
- `schemas/`：书源格式结构定义
- `runtime/`：独立选择器执行模块、通用适配器和文章质量检查
- `scripts/`：扫描、去重、格式转换和校验工具
- `imports/`：扫描目录、批次计划和审查记录；[查看 5152 条去重元数据目录](imports/aoaostar/public-catalog.json)
- `docs/`：书源格式、兼容性和开发说明
- `.github/workflows/`：自动校验

## 安全与来源要求

- 只收录具有合法使用和分发依据的书源。
- 不公开复制未经许可的第三方规则、Cookie、账号凭据或令牌。
- 不绕过登录、付费墙、验证码或 DRM。
- 不将未经授权的小说正文提交到仓库。

## 当前进度

已完成上游集合结构扫描、去重统计、格式分析、批次转换审查、JSON 索引与模板、无网络选择器执行模块、通用书源适配器、书源生成器、四阶段功能测试器和文本质量扫描器。

扫描候选和静态转换结果不等于已授权或已验证可用的正式书源。正式书源须逐个完成许可审查、结构校验和阅读 App 兼容测试。
## 书源分组

仓库对 App 只提供一个订阅：**小说源**。普通小说与成人小说统一收录，不再拆分订阅入口。旧版 `adult-subscription.json` 仅保留为历史规则归档，待逐条转换为 App 可识别格式后并入唯一订阅。
