# 个人小说书源仓库

这是一个独立的书源文件仓库，专门用于整理、维护和分发可由阅读 App 导入的书源配置。

**本项目只做书源，不开发或托管小说网站、在线阅读平台、用户系统或服务器服务。**

## 仓库内容

- `sources/`：书源 JSON 配置与解析规则
- `index.json`：书源总索引，供阅读 App 获取和导入
- `schemas/`：书源格式规范
- `runtime/`：书源选择器执行模块
- `scripts/`：书源扫描、去重、格式分析、转换和校验工具
- `imports/`：上游格式的扫描目录、批次计划和审查记录
- `docs/`：书源格式、兼容性和开发说明
- `.github/workflows/`：自动检查书源文件和脚本

## 书源格式

书源使用 JSON 保存元数据和规则，JavaScript 解析器负责将书源规则转换为搜索结果、书籍详情、目录和章节内容。

书源所指向的内容站点只是规则的目标来源；本仓库不提供站点服务，也不托管小说正文。阅读 App 在用户使用书源时，按书源规则访问对应来源。

## 安全与来源要求

- 只收录具有合法使用和分发依据的书源。
- 不公开复制未经许可的第三方源规则、Cookie、账号凭据或令牌。
- 不绕过登录、付费墙、验证码或 DRM。
- 不将未经授权的小说正文提交到仓库。
- 解析器应由阅读 App 在受限环境中运行，并遵守来源站点的访问限制。

## 当前进度

已完成书源集合结构扫描、记录去重、格式分析、批次转换审查、JSON 索引与模板，以及第一阶段无网络选择器执行模块。

目前的扫描候选和静态转换结果不等于已授权、已验证可用的正式书源。正式书源需要逐个确认来源许可、规则完整性和实际兼容性。
